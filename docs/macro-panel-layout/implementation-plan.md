# 宏观详情布局实施与验收

DCA当前授权口径更新于2026-11-03，替代v1.7.0／v1.7.1的加权评分，详见[因子方案](../nasdaq-dca-indicator/factor-redesign-proposal.md)。新规则随v1.8.0实现，发布前33项功能回归通过。下方旧版历史验收仍与本版分别记录。

## 折叠摘要

- 默认折叠，使用localStorage键`nas_macro_expanded`记忆展开偏好。
- 按可用宽度显示定投建议、纳指期货、美债10Y收益率与情绪；不重复展示利差或倒挂提示。
- 四项标题统一12px、中等字重及灰色，数值保留强调色。
- 按钮使用“展开详情 / 关闭详情”，文字单行且不压缩。

## 展开详情

1. 宏观七格展示纳指/标普期货、WTI/布伦特原油、离岸人民币、美债2Y/10Y；≥1280px时七列，640～1279px时四列，<640px时两列，中小屏美债10Y卡横跨两列。10Y−2Y利差以美债10Y标题旁的“正常利差／倒挂警报”状态展示，悬停查看实时bp利差；无有效利差不显示状态，不设独立卡片、不重复展示百分点。美债10Y数值旁的bp仍表示收益率日变动。原油为美元/桶，涨跌幅相对昨结算价，时间取上游报价时间，悬停时间可看日期；失效时价格、涨跌及时间显示`--`。原油合并到现有新浪请求，单项失效独立，不参与DCA决策、ETF计算或归档。
2. 桌面宽度≥1024px时，风向标与情绪卡各占一半；小于1024px上下排列。
3. 两张卡最小高度170px，内容增加时自然增高；仪表最大宽度160px，卡内边距10px、风向标纵向间距6px；30日图表容器最小110px，手机图表高度110px。
4. 情绪内部摘要在左、图表在右；小于480px时改为上下排列。

## 风向标（新授权规则）

- 保留左侧下方支点／上方半圆仪表及右侧三行数值，沿用上述紧凑高度、宽度与间距；三个等宽行动区为加投／正常／停投，指针只落离散行动，中心显示`1.5×／1×／0×`，底部为行动图例，不显示风险评分、权重或加权百分数。
- PE指上游PE分位，与情绪均为0～100，是两个决策输入；美债10Y标明环境背景，不参与行动判定。PE-TTM和利差不新增到卡内，不恢复52周位置。
- 默认正常1B；`(PE≤30 且 情绪≤25) 或 (PE≤15 且 情绪≤45)`候选加投1.5B，受用户预留预算上限约束；`PE≥85 且 情绪≥75`候选停投0B，其余正常。加投后以`PE>40 或 情绪>45`候选退出正常；停投后以`PE<80 或 情绪<65`候选退出正常。
- 每次转换含首次确认须同一候选连续3次合格评估，候选变化重新计数，断档／缺测／无效中断计数；确认期间保留原已确认行动。首次有效数据暂按正常1B并标“信号观察中”，候选满3次才确认。
- 独立标准库后端`/api/nasdaq-dca`通过后台循环及API共用评估逻辑；北京时间周一至周五16:00起每天最多一次，之前不新增评估，漏过日期不补算，周末不算断档。说明当前没有节假日日历，仅按星期判断。状态持久化到`data/nasdaq_dca_state.json`并须排除Git；不改变ETF计算或归档。
- 真实有效缓存可参与，估值超过7天或情绪`as_of`超过72小时不能确认新建议，不编造历史。数据失败保留原行动及最后成功评估时间；无已确认行动显示“数据不足，按自己的计划执行”，不显示信号，仪表采用灰色等待状态。
- 保留顶部摘要行动，详情不恢复重复建议横幅；常显规则解释、评估日期及最后成功评估时间；候选进度改为“加码信号观察中：已满足1天，连续满足3天后生效”等完整句子。停投确认后，仅在已有持仓且超过预设配置目标时提示“考虑止盈”，不自动卖出。
- 估值日期、情绪`as_of`、成功拉取时间及来源保留可查；源日期不被页面刷新时间替代，极窄宽度可横向查看时间与来源，不显示情绪缓存标签。
- 仪表悬浮、键盘聚焦或点击仅显示金额倍数及连续确认的简短说明；精确入场阈值、退出缓冲、评估时钟、预算上限及止盈说明放入卡内默认折叠的“规则说明”，展开阅读，避免长浮层遮挡页面。关键解释也须常显。保留手机点击切换及失焦收起、现有圆角／边框／阴影／明暗样式、指针过渡与减少动态效果偏好。

## 情绪及维护入口

- 情绪卡不显示“缓存数据”标签，继续展示温度、五段色温和最近30日趋势。
- “数据时间”绑定as_of，“最近拉取”绑定last_success_at；页面读取缓存不更新这两个源时间。
- 展开详情后在nextTick重绘Canvas，尺寸变化由ResizeObserver触发重绘。
- “同步标的”位于底部默认折叠的“投资风控要点与数据源说明 → 标的池维护”，保留原位反馈和同步中禁用。顶部仅保留主题与日常刷新操作。
