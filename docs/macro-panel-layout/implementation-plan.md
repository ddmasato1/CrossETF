# 宏观详情布局实施与验收

正式版本基线：v1.7.0（2026-10-23）。本文件描述main界面，包含已推送但未创建新标签的信号灯与详情去重调整，评分规则见[因子方案](../nasdaq-dca-indicator/factor-redesign-proposal.md)。

## 折叠摘要

- 默认折叠，使用localStorage键`nas_macro_expanded`记忆展开偏好。
- 按可用宽度显示定投建议、纳指期货、美债10Y收益率与情绪；不重复展示利差或倒挂提示。
- 四项标题统一12px、中等字重及灰色，数值保留强调色。
- 按钮使用“展开详情 / 关闭详情”，文字单行且不压缩。

## 展开详情

1. 宏观六格保留期货、汇率、美债2Y/10Y与10Y−2Y利差，倒挂提示在利差卡中展示。
2. 桌面宽度≥1024px时，风向标与情绪卡各占一半；小于1024px上下排列。
3. 两张卡最小高度190px，内容增加时自然增高；30日图表容器最小130px。
4. 情绪内部摘要在左、图表在右；小于480px时改为上下排列。

## 风向标

- 标题行显示名称、综合参考分和绿灯/黄灯/红灯标签；分别对应<30、30～70、>70分，使用绿色/黄色/红色。无有效分数时不显示灯号。
- 详情不再重复显示买入建议横幅；买入建议只保留折叠摘要栏。三因子使用三列，标签在上、数值在下。
- PE分位60%、情绪25%、美债15%；PE-TTM和利差不出现在卡内。
- 估值日期、成功拉取时间与来源为单行，极窄宽度可横向滚动查看。
- 评分悬浮或键盘聚焦显示三档浮层，使用与情绪温度一致的圆角、边框、阴影及明暗样式。
- 有效缓存继续评分；没有有效因子不评分，不显示情绪缓存标签。

## 情绪及维护入口

- 情绪卡不显示“缓存数据”标签，继续展示温度、五段色温和最近30日趋势。
- “数据时间”绑定as_of，“最近拉取”绑定last_success_at；页面读取缓存不更新这两个源时间。
- 展开详情后在nextTick重绘Canvas，尺寸变化由ResizeObserver触发重绘。
- “同步标的”位于底部默认折叠的“投资风控要点与数据源说明 → 标的池维护”，保留原位反馈和同步中禁用。顶部仅保留主题与日常刷新操作。
