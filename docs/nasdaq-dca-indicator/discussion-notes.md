# 纳指定投风向标决策记录

2026-11-03用户授权以下规则，替代旧60/25/15加权评分及30/70分档；完整定义见[因子方案](factor-redesign-proposal.md)。上述规则随v1.8.0实现，按用户要求在提交发布前集中测试，33项功能回归通过。

| 事项 | 当前已确认决定 |
| --- | --- |
| 使用场景 | 纳指长期定投参考，独立于A股ETF溢价、计算与归档 |
| 决策输入 | PE为上游PE分位，与情绪均为0～100；美债10Y仅作环境背景，无风险评分或权重 |
| 默认及加投 | 正常1B；`(PE≤30 且 情绪≤25) 或 (PE≤15 且 情绪≤45)`进入加投候选，确认后1.5B且不超过用户预留预算 |
| 停投及止盈 | `PE≥85 且 情绪≥75`进入停投候选，确认后0B；仅在已有持仓且超过预设配置目标时补充“考虑止盈”，不自动卖出 |
| 退出缓冲 | 加投以`PE>40 或 情绪>45`退出至正常；停投以`PE<80 或 情绪<65`退出至正常 |
| 确认 | 每次转换含首次确认均须同一候选连续3次合格评估；候选变化重新计数，漏评／缺测／无效中断计数，期间保留原已确认行动 |
| 评估时间 | 北京时间周一至周五16:00起每天最多一次，后台循环与API共用状态；之前不新增评估，不补算漏过日期；仅按星期判断，无节假日日历，周末不算断档 |
| 缓存与时效 | 接受真实有效缓存，不编造历史；估值超过7天或情绪`as_of`超过72小时不能确认新建议，保留并显示源日期 |
| 初始及失败 | 初始有效数据暂为正常1B并标“信号观察中”，满3次才确认；失败保留原行动及最后成功评估时间，无已确认行动时显示“数据不足，按自己的计划执行”，不发信号 |
| 后端与持久化 | 独立标准库`/api/nasdaq-dca`，状态写`data/nasdaq_dca_state.json`并排除Git，供重启恢复与每日去重 |
| 仪表 | 三个等宽行动区，指针只落离散行动；中心`1.5×／1×／0×`，不显示风险分或加权百分数 |
| 解释与交互 | 常显解释、评估日期及“加码信号观察中：已满足1天，连续满足3天后生效”等完整进度句；悬浮仅简述倍数及连续确认，阈值、退出缓冲、时钟、预算及止盈前提移至默认折叠的“规则说明”，保留悬停／键盘／手机点击 |
| 布局 | 保留紧凑170px最小卡高、160px仪表、110px图表及当前响应式／主题细节，右侧PE与情绪标为决策输入，10Y为背景；源日期／成功拉取时间／来源可查 |
| 保留边界 | 不恢复52周位置或额外usQQQ请求；PE-TTM不加入决策，利差只作宏观展示；不改变ETF计算或归档 |
| 数据源 | 现有腾讯／新浪未取得可用PE字段，沿用雪球基金公开估值和FearGreedFlow情绪；ChartExchange仅为调研，未接入 |

本次选择以可解释的行动规则为主，未进行策略回测或参数优化。数据口径与来源限制见[估值源评估](valuation-source-assessment.md)和[ChartExchange评估](chartexchange-source-assessment.md)。

v1.7.0／v1.7.1的12项核心、5项并发及评分／界面验证保留为旧版历史记录，不作为新规则验收结论，旧加权评分验收不再适用。v1.6.0及后续旧模型见[CHANGELOG](../../CHANGELOG.md)，不恢复为当前规则。开发期间未逐次运行测试；v1.8.0发布前按用户授权集中执行，12项核心、5项并发、2项年初涨幅、4项原油及10项每日定投状态机回归全部通过，策略阈值仍未回测。
