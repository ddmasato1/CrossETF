# 纳指定投风向标决策记录

当前交付版本为v1.7.0（2026-10-23）；完整规则见[因子方案](factor-redesign-proposal.md)。以下仅保留仍影响当前实现的已确认决策，过渡试用方案不再作为执行依据。

| 事项 | 已确认结果 |
| --- | --- |
| 使用场景 | 纳指长期买入参考，剥离A股ETF场内溢价 |
| 因子数量 | 采用PE分位、情绪、美债10Y三项，权重60%/25%/15% |
| 分档 | 综合分保留一位小数，30与70分为边界，共三档 |
| 金额文字 | 评分浮层展示1.5倍、1.0倍、暂停或0.5倍；不引入金额计算 |
| 缓存 | 有效旧值继续评分，成功获取新数据再替换 |
| 缺失 | 不补中性分、不重新分配权重，没有有效输入不生成建议 |
| 非计分项 | PE-TTM不展示于卡内，利差仅在展开宏观区展示 |
| 52周位置 | 前后端删除，取消额外usQQQ请求 |
| 数据查询 | 优先检查腾讯/新浪现有接口；PE字段不可用后采用雪球基金公开源 |
| 备用源 | ChartExchange仅完成调研，未接入 |
| 布局 | 三因子同行，估值日期/拉取时间/来源同行，评分带自定义浮层 |
| 标签 | 标签按绿灯/黄灯/红灯分类，主建议保持行动文案，去掉情绪缓存文字 |
| 验证产物 | 临时脚本、预览页、截图不进入仓库，正式回归测试保留 |

当前规则的选择以简单可理解为主，未进行策略回测。具体数据口径与来源限制见[估值源评估](valuation-source-assessment.md)和[ChartExchange评估](chartexchange-source-assessment.md)。
