# 纳指定投风向标需求分析

- 当前文档描述main；评分基线v1.7.0已发布，后续信号灯与详情建议去重已推送main，尚未创建新版本标签。
- 目标：利用已收集数据提供简洁的纳指买入参考，独立于场内ETF溢价。
- 实现细节以[因子方案](factor-redesign-proposal.md)为准。

## 评分需求

1. PE分位60%、恐惧贪婪指数25%、美债10Y收益率15%，总分0～100，保留一位小数。
2. PE分位和情绪直接使用0～100值，美债在2%～6%之间线性映射并截断。
3. `<30`、`30～70`（含边界）、`>70`三档，主建议分别为“可以考虑买入”“谨慎买入”“放缓或暂停买入”。
4. 评分悬浮浮层显示对应的1.5倍、保持1.0倍、暂停或0.5倍金额文案；高档保留止盈补充文字。金额仅为展示，不涉及持仓或交易计算。
5. 三个因子必须有有效数值，缺失不补中性分、不重新分配权重；已有有效缓存持续评分，成功获取新值后更新。

## 展示需求

- 灯号按<30绿灯、30～70黄灯、>70红灯分档，配套绿色/黄色/红色；没有有效分数时显示灰色等待状态。

- 三项因子同行，标签在上、数值在下；PE-TTM与利差不在风向标内展示。
- 买入建议仅在折叠摘要栏显示；估值日期、成功拉取时间及来源同行。
- 评分悬停或键盘聚焦时显示浮层，沿用情绪温度的视觉样式。
- 不显示情绪缓存标签；情绪数据时间、最近成功拉取时间分别保留。
- 52周位置从前后端清理；利差仅保留展开宏观区展示。

## 数据与系统边界

- 估值接口固定上游、独立6小时冷却与持久缓存；情绪独立60分钟缓存及10分钟失败重试间隔。
- 前端启动、手动刷新和6小时定时器读取估值；秒级行情轮询不调用估值接口。
- 不影响ETF的IOPV估值、溢价、排序、价差测算及历史归档。
- 纯Python标准库服务端、Vue和Tailwind CDN前端，不引入构建或数据库依赖。
- 12项核心回归与5项并发检查通过，当前权重未经过策略回测或参数优化。
