# 纳指定投风向标需求分析

当前授权口径更新于2026-11-03，替代60/25/15加权评分。目标是独立于场内ETF溢价提供定投行动参考，完整规则见[因子方案](factor-redesign-proposal.md)。新规则随v1.8.0实现，发布前33项功能回归通过；阈值未做策略回测。

## 行动需求

1. PE指纳指100的上游PE分位，情绪为恐惧贪婪指数，均为0～100；美债10Y仅作环境背景，不计分、不参与行动判定。
2. 默认正常1B。满足`(PE≤30 且 情绪≤25) 或 (PE≤15 且 情绪≤45)`候选加投1.5B，金额不得超过用户预留预算；满足`PE≥85 且 情绪≥75`候选停投0B；其余正常。
3. 加投后以`PE>40 或 情绪>45`候选退出至正常；停投后以`PE<80 或 情绪<65`候选退出至正常。每次转换及首次确认都须同一候选连续3次合格评估，确认前保留原已确认行动。
4. 停投确认后，仅对已有持仓且超过预设配置目标提示“考虑止盈”，不自动卖出。
5. 初次有效数据暂按正常1B并显示“信号观察中”，直到3次确认；数据失败保留原行动与最后成功评估时间，没有已确认行动则显示“数据不足，按自己的计划执行”，无信号。

## 评估与持久化需求

- 独立Python标准库后端`/api/nasdaq-dca`，后台循环和API共用每日去重及状态转换逻辑；北京时间周一至周五16:00起每天最多评估一次，之前不新增评估。当前没有节假日日历，须披露仅按工作日星期判断。
- 漏过的应评估日不补算；缺测、无效或日期断档中断连续计数，候选变化重新计数，周末不算断档。
- 允许真实有效缓存参与，不虚构历史；估值超过7天、情绪`as_of`超过72小时不得确认新建议，展示源日期及成功拉取时间。
- `data/nasdaq_dca_state.json`持久化已确认行动、候选计数、每日评估记录与最后成功评估时间，重启恢复；运行状态文件须排除Git，不暂存或提交。

## 展示与系统边界

- 三个等宽行动区加投／正常／停投，指针定位离散行动，中心为`1.5×／1×／0×`；去除风险评分、权重及加权百分数。
- 保持左仪表右三行数值、170px最小卡高、160px仪表上限、110px图表及响应式／明暗主题细节；PE分位与情绪标为决策输入，10Y标为环境背景。PE-TTM与利差不新增到卡内。
- 顶部摘要保留行动，详情不恢复重复建议横幅；常显解释、评估日期、数据状态及完整进度句，例如“加码信号观察中：已满足1天，连续满足3天后生效”。悬浮仅简述投入倍数和连续确认，支持悬停／键盘／点击；入场阈值、退出缓冲、时间限制、预算上限与止盈前提放入默认折叠的“规则说明”。
- 保留估值日期、情绪`as_of`、最近成功拉取时间及来源，页面刷新不替代源时间；不显示情绪缓存标签。没有可用状态时使用灰色等待展示。
- 沿用估值独立6小时冷却、情绪60分钟缓存及10分钟失败重试；不恢复52周位置或usQQQ额外请求，不改变ETF的IOPV、溢价、排序、价差及收盘归档，无新增依赖或数据库。
