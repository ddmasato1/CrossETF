# 纳指100估值数据源可用性核查

日期：2026-10-23。当前状态：公开估值观察已在本地接入；本轮完成口径公开资料核查及来源标签纠正，仍不生成评分或交易信号。下文按时间记录调查过程。

## 当前结论与优先级

用户要求优先复用腾讯、新浪。实际检查现有行情接口及新浪QQQ补充接口后，本次没有取得可用于纳指100估值判断的PE。现有价格和52周高低点不能替代盈利数据，更不能据此生成十年估值分位。

结论仅适用于本次核查的接口与响应，不能推断腾讯、新浪所有服务都没有指数估值数据。尚未确认它们有可直接复用的十年同口径PE接口。

最初阶段保持固定定投基准及“估值数据待接入”；后续已按用户批准接入雪球基金只读观察，详见后续记录。未采购订阅或联系供应商。

### 新浪字段依据

读取[新浪官方QQQ页面](https://stock.finance.sina.com.cn/usstock/quotes/QQQ.html)及其引用的官方脚本，而非照抄第三方字段表：

- 页面PE标签的说明为“股价/每股收益TTM”。
- [tool.js](https://n.sinaimg.cn/finance/ushttps/js/tool.js?v=2024101716)中的美股解析函数使用零起始下标13读取EPS、14读取PE；无有效PE时显示`--`。
- [stock.js](https://n.sinaimg.cn/finance/ushttps/js/stock.js?v=2024101716)调用该美股解析器。补充信息请求存在，不代表补充接口含可用指数PE。
- 页面“历史价格”入口链接到Nasdaq价格页面；这不构成新浪提供历史估值序列的证据。

腾讯本次未取得可公开核验的美股字段规范，因此不将猜测的字段下标写入生产代码。对照个股字段非空，也不能证明其PE口径与指数加权方法。

### Siblis的定义与授权差异

[方法文档](https://siblisresearch.com/docs/Siblis-Research-Data-Methodology.pdf)说明其PE使用聚合市值与经正常化调整的TTM盈利，并自述保留当时可得信息。它不是未经调整的GAAP盈利PE；接入后必须标注供应商口径，历史与当前保持一致。对负盈利、缺失成分及指数权重的处理仍应取得足够样例核验，不把供应商的方法说明视为独立审计。

[API文档](https://siblisresearch.com/global-valuations-database/api/)区分免费快照与订阅历史数据。生产使用需确认NDX本身覆盖范围，不能把数据库“最长回溯1970年”理解为NDX从1970年开始。

[授权说明](https://siblisresearch.com/data-licensing/)允许署名复用公开数据页的当前值和十个年末值，但完整历史/API对应用用户展示需要单独核对再分发授权。普通个人订阅不自动覆盖CrossETF公网页面；免费年末点不足以计算本项目要求的十年月度分位。

## 后续判断门槛

1. 优先在腾讯、新浪找到可证实的估值服务；明确NDX与QQQ、TTM与预测PE、加权与亏损处理等口径。若只取得QQQ基金PE，应如实标注，不冒充指数官方PE。
2. 获得至少120个有效历史月末值，核对历史与当前算法一致，以及样本的实际发布时间与后续修订机制；日线K线不是估值历史。
3. 若只能得到当前PE，可另行讨论“仅展示当前供应商口径PE”，不能同时展示十年分位、贵便宜结论或金额调整。
4. 月度观察无需秒级估值请求。确认数据源后再设计低频缓存、最后有效值及时间说明；不新增公开触发采集接口，不把密钥放到浏览器。
5. 若现有源无法满足，再由用户决定是否采用外部数据授权或保持估值待接入。不能为了凑齐指标改回价格位置打分。

本次没有策略回测，也没有投资表现结论；仅更新数据可用性判断。


## 公开数据源补充核查（2026-10-23）

用户进一步要求寻找公开数据。已找到可无需登录和密钥查询的候选；不能据此认为取得了完整历史序列或稳定服务承诺。本次仍未接入生产。

### 优先候选：雪球基金（原蛋卷）估值中心

- [官方说明](https://danjuanfunds.com/article/337.html)明确指标为PE-TTM，基础数据主要来自Choice；百分位采用近十年，不足十年取全部历史。该旧说明提到NDX从2012-01-04开始，但不能以旧文章替代本次实际历史覆盖核验。
- 实查[公开JSON](https://danjuanfunds.com/djapi/index_eva/dj)，HTTP 200，无需账户/密钥；`data.items`中能按`index_code=NDX`取得纳指100。响应为当前估值列表，不是完整PE历史。
- 本次样例：`pe=28.7417`、`pe_percentile=0.388`（38.8%）、`pe_over_history=0.612`（互补字段，不能反向当成分位）。数据日期`ts`转换为北京时间2026-10-22，`updated_at`为2026-10-23 09:32:00；获取时刻与估值日期应分开显示。
- 当前`begin_at`转换为北京时间2016-07-06，与旧文章起点不同。它是否代表当前百分位窗口、底层数据起点或其他业务日期尚未证实。不能直接宣称该响应已验证十年同口径历史，也不能把上游日度分位称为本项目自算的十年月度分位。
- `eva_type=high`不是金额或止盈信号。官方说明此分类还使用盈利收益率与默认国债收益率比较，不能照搬进本项目。
- 可优先提出“只展示来源标注的当前TTM PE与上游PE分位”的接入方案；不改变固定定投。生产使用仍需核对当前条款及自动访问/再展示范围；尚未确认正式开发者API、限额和服务稳定性。
- 尚未找到经验证的该站完整NDX历史PE下载接口。公开备份项目DJEVA及使用它的[时间的朋友说明](https://friendstime.top/history)展示的PE覆盖仅2022年以后，也不足十年，不混入其他供应商补齐。

### 对现有计划的影响

已找到公开“当前PE+上游分位”的可行线索，不能继续笼统称为完全没有公开估值数据。但完整、可复算、十年月度且符合当时可得信息的TTM序列仍未验证。

建议下一步优先核验雪球基金口径与使用条件，若满足则先做低频只读估值展示，明确标注“上游PE分位”，不输出金额档位、不复制其高低估标签。自算十年分位与历史回测继续等待原始序列，不因公开数据难找降低数据定义。

### 亏损股处理：找到历史依据，当前实现仍未完全确认

雪球基金账号发表过[《指数估值中心PE计算方法调整说明》](https://xueqiu.com/9485866208/128488024)，搜索索引摘要显示其将PE-TTM由剔除负值改为不作调整，即保留亏损。该历史公告是供应方说明，不是其他用户推测。

但本次正文访问仅返回动态页面，当前估值页帮助及NDX详情接口没有进一步列出NDX的亏损处理、聚合/加权公式、变更日期或历史重算策略。因此只能记录历史政策，不能声称已验证2026年NDX算法完整沿用且历史没有断点。

### 仍不知道的事项

1. `begin_at`为2016-07-06，而旧文章提及2012-01-04。当前代码只在排序状态中出现该字段，没有公开解释它是数据起点、业务起点还是窗口起点；差异原因仍不知道。
2. 当前NDX到底如何按指数权重/市值聚合、缺失盈利和亏损成分如何逐项处理，以及历史是否使用当时成分股，未取得足够证据。
3. 百分位具体样本频率、节假日是否填充、同值的排名方法、滚动边界是否包含当天、是否因财报重述回修历史，尚未披露或未查到。

旧文章的2012起点、当前begin_at及近十年规则可能描述不同概念；不能为了使它们一致而自行编造解释。当前/历史原始序列尚未到手，也无法验证分位是否确实可复算。
