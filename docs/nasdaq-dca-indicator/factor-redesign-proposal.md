# 纳指定投风向标因子方案

## 当前授权规则（2026-11-03）

本规则随v1.8.0实现，替代旧版60/25/15加权评分及30/70分档。发布前33项功能回归通过，其中10项验证每日定投状态机；以下为当前实现口径，阈值尚未做历史策略回测。

## 行动与状态转换

PE指上游提供的纳指100 **PE分位（0～100）**，不是PE-TTM倍数；情绪指恐惧贪婪指数（0～100）。B为用户原定的每期定投基准金额，默认正常定投1B。

| 当前状态 | 候选转换条件 | 确认后的行动 |
| --- | --- | --- |
| 正常／尚无已确认状态 | `(PE≤30 且 情绪≤25) 或 (PE≤15 且 情绪≤45)` | 加投1.5B，实际金额不得超过用户预留预算 |
| 正常／尚无已确认状态 | `PE≥85 且 情绪≥75` | 停投0B |
| 正常／尚无已确认状态 | 其余有效输入 | 正常1B |
| 加投 | `PE>40 或 情绪>45` | 退出加投，恢复正常1B；未满足则维持加投 |
| 停投 | `PE<80 或 情绪<65` | 退出停投，恢复正常1B；未满足则维持停投 |

- 每次转换，包括首次确认、加投或停投退出，都要求同一候选连续3次合格评估；候选变化重新计数，缺测、无效数据或漏过应评估日中断计数。缓冲期间保留原已确认行动。
- 首次取得有效数据时暂按正常1B展示“信号观察中”，直到候选完成3次确认；临时默认值不等于已确认信号。
- 只有停投已确认后才附加“考虑止盈”：须已有持仓且超过事先设定的配置目标；不自动卖出，也不把停投等同于清仓。

## 评估时钟与数据质量

- 后端以北京时间周一至周五16:00及以后每天最多评估一次，后台循环和`/api/nasdaq-dca`共用同一评估状态，重复请求不累加次数；截止时刻前只返回既有状态。
- 当前只按星期判断，没有节假日日历，工作日假期也可能评估，须在界面说明。周末不算漏评；服务停机等漏过应评估日时不补算，后续连续计数重新开始。
- 可复用真实有效缓存，不要求每天获得不同源日期，但不得编造历史评估或回填漏过日期；显示估值日期、情绪`as_of`与最近成功拉取时间，拉取时间不替代源日期。
- 估值日期超过7天，或情绪`as_of`超过72小时，均不能用于确认新建议（含首次确认及退出），并中断候选计数。
- 数据失败、缺失或无效时，保留原已确认行动和最后成功评估时间，并说明数据异常；没有已确认行动时显示“数据不足，按自己的计划执行”，不输出信号。失败日不得伪装成成功评估日。

## 后端与系统边界

- 新增独立标准库后端`/api/nasdaq-dca`承载判定；前端读取后端状态，不自行按页面刷新累计确认。
- 状态持久化至`data/nasdaq_dca_state.json`，保存已确认行动、候选及计数、当日评估记录和最后成功评估时间，供重启恢复及每日去重；该运行文件须被Git排除，不暂存、不提交。已在`.gitignore`排除状态文件及其临时文件。
- 沿用`/api/nasdaq-valuation`的NDX估值、`/api/fear-greed`的情绪数据。估值成功或失败均冷却6小时，情绪成功缓存60分钟、失败后10分钟允许重试；源缓存可展示与能否确认新建议分别判断。
- PE分位沿用上游口径，不在本地重建历史分位。估值来源为雪球基金（原蛋卷），情绪来源为FearGreedFlow；美债10Y沿用现有宏观行情，仅作环境背景，不参与决策，也不因缺失而阻断PE／情绪判定。
- 不引入第三方依赖或数据库，不改变ETF估值、溢价、排序、价差计算及历史归档。52周位置及额外usQQQ请求不恢复；PE-TTM与利差不新增到决策输入。

## 界面口径

- 保持当前紧凑布局：卡片最小170px、仪表最大160px、图表最小110px及现有响应式、明暗主题和交互细节；说明可使内容自然增高。
- 半圆仪表为三个等宽行动区：蓝色“加大投入”、中性灰“正常投入”、橙色“停止投入”；图例与顶部建议标签同步配色，行动文字优先，不使用红黄绿灯概念，也不把颜色解读为涨跌预测。指针只落在离散行动位置，中心显示`1.5×／1×／0×`，不显示风险评分、权重或加权百分数；“考虑止盈”保持独立附加提示。观察中的正常位置须标注未确认；没有可用状态时使用灰色等待展示。
- 右侧保留PE分位、情绪及美债10Y三行数值，前两项标明决策输入，10Y标明环境背景；估值日期、情绪源时间、最近成功拉取时间及来源可查。
- 保留顶部摘要行动、详情不重复建议横幅、不显示情绪缓存标签等当前细节；常显规则解释、评估日期及最后成功评估时间。候选进度使用完整句子，例如“加码信号观察中：已满足1天，连续满足3天后生效”，分别对应加码、停投或恢复正常投入，不用易被误认为投入比例的X/3缩写。
- 仪表浮层仅简述投入倍数和连续3个评估日确认，支持悬停、键盘聚焦与手机点击；表内入场阈值、退出缓冲、16:00后工作日每日一次、预算上限及有条件止盈改放在默认折叠的“规则说明”中，展开后在卡内阅读，避免长浮层遮挡页面。沿用现有主题与减少动态效果处理。
