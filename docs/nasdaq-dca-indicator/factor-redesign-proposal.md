# 纳指定投风向标因子方案

## 当前实现口径（v1.7.0，2026-10-23）

本节为最新确认结果，下文早期方案与过程记录以本节为准。

- 评分权重：PE分位60%、恐惧贪婪指数25%、美债10Y收益率15%；美债按2%→0分、4%→50分、6%→100分线性映射并截断。综合分先保留一位小数，再按30/70分分档。
- 有效缓存持续评分，过期或刷新失败不阻断建议；新数据获取成功后替换。缺失或无效输入不补中性值、不重分配权重，不生成评分。

| 分数范围 | 卡片主建议 | 评分浮层文案 |
| --- | --- | --- |
| 0≤分数<30 | 可以考虑买入 | 可以增加至1.5倍金额 |
| 30≤分数≤70 | 谨慎买入 | 买入，保持1.0倍金额 |
| 70<分数≤100 | 放缓或暂停买入 | 暂停买入，或者0.5倍金额买入 |

- 高档仍保留“已有持仓可考虑适当止盈”补充说明。此次倍数调整仅修改浮层文案，不增加金额计算，不改变权重、阈值或卡片主建议。
- 评分浮层复用情绪温度的圆角、边框、阴影及明暗主题样式，悬停评分或键盘聚焦时显示，替代原生title提示。
- 卡内仅显示三项评分因子，三列同行、标签在上数值在下；移除PE-TTM与利差。估值日期、成功拉取时间及来源合并一行，极窄屏可横向滚动。
- 删除风向标情绪旁“· 缓存”及独立情绪卡“缓存数据”标签，保留数据时间、最近成功拉取时间及后台缓存机制。
- 摘要栏四个标题统一12px、中等字重与灰色；摘要仅显示10Y收益率，不再重复利差或倒挂提示，完整利差信息在展开宏观区保留。
- v1.7.0发布采用以上规则；开发分支为`codex/dca-factor-redesign`，合并至`main`。12项核心回归与5项并发检查通过；临时预览文件已清理。


## 因子取舍

- PE分位为主要因子，情绪和美债收益率共同影响评分。三项统一为0～100，数值越高，建议越谨慎。
- PE-TTM是同一估值信息的原始值，不作为第四项计分；仍由估值接口返回，用于校验与数据口径追溯。
- 利差保留宏观展示，不加入定投评分，避免增加重复因子。
- 52周位置已从前后端删除，不再附加usQQQ行情请求。
- 60/25/15权重及30/70阈值是用户确认的简化产品规则，未进行最优参数验证或策略回测。

## 数据源与接口

- `/api/nasdaq-valuation`：雪球基金（原蛋卷）公开估值，取NDX的PE-TTM及上游PE分位；不采用其高低估分类。
- `/api/fear-greed`：FearGreedFlow公开情绪数据，独立缓存。
- `/api/quotes`：美债10Y收益率沿用新浪宏观行情，不新增美债请求。
- 当前PE分位沿用上游口径，不在本地重建历史分位；当前指数PE的完整聚合算法尚未核实，见[估值数据源评估](valuation-source-assessment.md)。
- 腾讯和新浪现有查询未取得可用的纳指PE字段，因此估值使用独立公开源。[ChartExchange评估](chartexchange-source-assessment.md)仅为备用源调研，未接入运行链路。

## 缓存与异常

估值成功或失败均冷却6小时，最近尝试时间和最后有效快照原子写入`data/nasdaq_valuation_cache.json`，重启后恢复。固定上游，无强制刷新及任意URL参数；没有有效估值时返回503，旧数据降级返回200及状态字段。

情绪成功缓存60分钟，失败后10分钟内不重复请求。前端保留有效旧值参与评分，不将刷新时刻伪装为数据时间。没有有效输入时显示“数据不足”，加载中显示“正在读取数据”。

估值、情绪及评分均不参与ETF估值、排序、价差测算或收盘归档。运行缓存不提交Git。
