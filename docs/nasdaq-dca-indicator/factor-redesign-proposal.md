# 纳指定投风向因子重构提案

## 当前实现口径（v1.7.0，2026-10-23）

本节为最新确认结果，下文早期方案与过程记录以本节为准。

- 评分权重：PE分位60%、恐惧贪婪指数25%、美债10Y收益率15%；美债按2%→0分、4%→50分、6%→100分线性映射并截断。综合分先保留一位小数，再按30/70分分档。
- 有效缓存持续评分，过期或刷新失败不阻断建议；新数据获取成功后替换。缺失或无效输入不补中性值、不重分配权重，不生成评分。

| 分数范围 | 卡片状态标签及主建议 | 评分浮层文案 |
| --- | --- | --- |
| 0≤分数<30 | 可以考虑买入 | 可以增加至1.5倍金额 |
| 30≤分数≤70 | 谨慎买入 | 买入，保持1.0倍金额 |
| 70<分数≤100 | 放缓或暂停买入 | 暂停买入，或者0.5倍金额买入 |

- 高档仍保留“已有持仓可考虑适当止盈”补充说明。此次倍数调整仅修改浮层文案，不增加金额计算，不改变权重、阈值或卡片主建议。
- 评分浮层复用情绪温度的圆角、边框、阴影及明暗主题样式，悬停评分或键盘聚焦时显示，替代原生title提示。
- 卡内仅显示三项评分因子，三列同行、标签在上数值在下；移除PE-TTM与利差。估值日期、成功拉取时间及来源合并一行，极窄屏可横向滚动。
- 删除风向标情绪旁“· 缓存”及独立情绪卡“缓存数据”标签，保留数据时间、最近成功拉取时间及后台缓存机制。
- 摘要栏四个标题统一12px、中等字重与灰色；摘要仅显示10Y收益率，不再重复利差或倒挂提示，完整利差信息在展开宏观区保留。
- v1.7.0发布采用以上规则；开发分支为`codex/dca-factor-redesign`，合并至`main`。12项核心回归与5项并发检查通过；临时预览文件已清理。

## 目标与结论

面向长期、定期投入纳斯达克100的新资金，优先保证规则可理解、资金安排可持续。它不承担短线涨跌预测，也不直接管理既有持仓的卖出。

建议从“四因子加权风险分 → 五档金额 → 止盈”改为“固定定投基准 + 单一估值观察 + 独立市场背景”。当前不再寻找一组新的主观权重。估值数据和策略验证通过前，默认展示“按原计划定投”，不输出伪装成模型结论的低估、泡沫或精准风险分。

## 主流方法的适用范围

| 方法 | 主要解决什么 | 本项目取舍 |
| --- | --- | --- |
| 固定金额定投 | 规律投入、减少择时决策 | 默认基准；新方法必须与它公平比较 |
| 估值调整 | 长期预期回报与买入价格是否匹配 | 唯一候选金额调整因子；不据此预测下月涨跌 |
| 趋势控制 | 调整市场暴露、控制持仓风险 | 暂不加入；它与下跌加投的逆向逻辑可能冲突，需要独立目标和验证 |
| 宏观周期择时 | 理解利率、增长和经济周期 | 保留背景，不把单个宏观阈值直接映射成买卖命令 |
| 情绪逆向 | 理解短期市场行为 | 保留现有情绪卡，不再独立占35%决定长期投入金额 |

Schwab的研究可支持把持续投入作为比较基准，但研究对象为标普500和特定现金流，不能直接证明纳指定投策略优劣。Vanguard强调估值对长期收益的解释作用，不把它作为短期择时工具。AQR的趋势研究涉及多资产期货等策略，不能直接证明“QQQ跌破某条均线就应停投”。

## 现有因子逐项取舍

| 当前项目 | 问题 | 建议 |
| --- | --- | --- |
| 情绪35% | 恐惧不等于便宜；广义市场情绪不等于纳指估值 | 移出金额计算，继续在情绪卡观察 |
| 10Y名义收益率30% | 固定3.5%、4.5%、5.2%分档没有本项目策略验证；同样利率可对应不同增长、通胀环境 | 保留宏观看板，移出金额计算 |
| QQQ 52周位置20% | `(价格−最低)/(最高−最低)`是区间位置，不是估值，也不是历史估值百分位 | 移出评分；不再称“估值平替”；无需再加一个回撤或均线评分来填补权重 |
| 10Y−2Y利差15% | 经济周期观察与具体纳指投入时点并不等价；简单把利差扩大解释为低风险缺乏验证 | 保留宏观看板，移出金额计算 |
| 纳指100估值 | 与价格位置含义不同，直接涉及为盈利支付的价格 | 新增研究候选；先核验同口径历史数据，再展示分位 |

利率和利差共享部分输入，情绪与价格也可能包含重叠信息；这里尚未测算实际相关系数，不声称它们已经通过统计检验。旧模型的35/30/20/15也不是经过验证的最优配置。

## 最小可行规则

### 第一阶段：可先落地的产品行为

1. 取消综合0–100风险分、四因子权重和0/0.5/1/1.5/2倍五档建议。
2. 主结论改为“按原计划定投”；说明“默认遵循固定金额计划，估值调整尚未启用”。这是一项用户选定的基准策略，不是系统判断市场安全。
3. 情绪、美债、利差继续放在各自卡片，不重复包装成决策因子。
4. 移除“悲观低估、极度泡沫、停投止盈”等无法由现有输入支撑的结论。既有持仓的止盈、资产配置和个人资金需求不由此模块推断。
5. 估值没有可靠数据时显示“估值数据待接入/不足”，不填50分，不生成估值分位。暂不增加VIX、RSI、MACD、额外均线等判断项。

### 第二阶段：估值先观察，再验证金额调整

- 只选择一条可长期维护的纳指100市盈率序列。优先核验TTM口径；预期PE需额外核验预测期限、历史预测快照与授权，暂不引入。两类PE不得混用。
- 候选展示：当前PE、过去10年同口径月度历史分位、数据时间、来源。十年是预先约定的研究窗口，不是已验证的最佳窗口。
- 分位以当时已公布、可取得的历史月度值计算；至少120个有效历史月度观测。比较样本只用决策时点之前的数据，并固定相等值的计算方法。没有足够数据就不显示分位。
- 固定月度决策频率；行情秒级刷新不改变当月投入档位。TTM非正、口径变化、发布时间不明或数据过期时停止估值判断。
- **唯一待测金额规则**：分位≤20%为1.25倍，20%–80%为1倍，≥80%为0.75倍（80%归高位档）。为避免边界歧义，具体实现为`p <= 20`、`20 < p < 80`、`p >= 80`。这些数值只是预先登记的候选，不能称为最优参数。
- 金额上调须有预留现金；最多使用当期预算与实际可用储备，不借用未来预算、不加杠杆、不自动卖出旧持仓补资金。无储备时上调受资金上限限制。低估可能继续下跌，高估可能长期延续。
- 未经过下述验证前，这套倍数仅用于研究，不作为页面的有效投资指令；若无法证明有实际价值，就保留固定定投。

## 数据核查结果与限制

2026-10-23通过已连接的iFinD指数查询核查NDX.GI在2026-10-22的样例：返回TTM PE 29.5707；预测PE为空，返回参数中的预测年度为2024，不满足未来12个月口径要求。此次查询没有确认过去十年同口径序列、历史快照或生产环境接入授权。该样例仅说明查询返回情况，不用来判断当前便宜或贵。

Invesco公开QQQ资料将PE定义为过去12个月盈利口径的加权调和平均。它可以帮助确认定义，不能与其他供应商的NDX PE或预期PE直接拼成历史序列；一份当前事实表也不能提供十年分位。

聊天中的数据连接可用，不等于本项目服务器已有可部署、可再分发的数据API。不能先承诺免费稳定接入，再用来源不明的抓取补缺口。新数据源需核对授权、缓存、失败回退和请求频率；不需要新增公开管理接口。

## 防止过拟合的验证门槛

1. 先固定上述唯一候选规则，不遍历几十组因子、窗口和权重选历史最好结果。少因子仍可能过拟合，必须保留验证边界。
2. 使用当时可得的估值和实际发布时间；信号形成后下一个可交易时点执行，不能用同一收盘价既生成信号又假定已成交。不得用今天修订的盈利或成分股重建“当时已知”估值。
3. 与固定定投使用相同初始资金、每月新增资金和现金收益假设；把保留现金、额外储备、交易成本和适用费用计入。上调资金不足时按同一资金约束执行，不能靠多投钱制造收益优势。
4. 报告期末总资产、现金流收益率、含现金组合的回撤及闲置现金。不能只比较买入均价，也不能把新入金造成的资产增加视为投资收益。
5. 按时间顺序划分研究与检验阶段、做滚动检验，并单列熊市和长期上涨阶段；最终检验阶段不得参与调参。若所有历史时期已经被反复查看，不能再声称它们是完全未见的样本，应增加未来模拟观察。
6. 少量相邻窗口或边界仅用于检验稳定性，不用于重新挑冠军。若效果只出现在个别参数、时间段，或收益改善主要来自额外现金，则不启用金额调整。

目前没有策略回测结果，不能声称新方案提高收益或降低回撤。代码单元测试只验证计算行为，不能验证投资有效性。

## 审核后任务顺序

1. 实施第一阶段：统一前后端输出语义、删除旧评分及倍数依赖，调整现有测试与界面说明；保留行情、情绪时间与现有安全边界。
2. 核验一个估值供应源的历史口径、可用性与生产授权；不满足条件就停留在第一阶段。
3. 数据满足条件后实现估值观察与缓存，先验证时间、缺失值、历史分位正确性。
4. 独立评估候选规则与固定定投；通过审核后才启用金额提示，同时更新说明与版本文档。

## 已确认三因子评分落地（2026-10-23，未发布）

用户确认权重及美债换算；此项取代此前PE分位100%、情绪与美债0%的展示规则。

- 综合分S=0.60×PE分位+0.25×恐惧贪婪指数+0.15×clamp((美债10Y收益率百分数−2)/4×100,0,100)。例如收益率4.949%对应73.725分，权重贡献约11.06分。
- 综合分四舍五入保留一位小数后分档：<30可以考虑买入、30～70（含边界）谨慎买入、>70放缓或暂停买入并提示已有持仓可考虑适当止盈。标签改为偏积极/中性谨慎/偏防守，避免将混合分误称估值分。

- 三项输入均须有效。估值或情绪读取失败、输入stale/data_old等状态时不显示分数与执行建议；不补中性值、不重新分配权重。原始缓存值和状态继续展示。
