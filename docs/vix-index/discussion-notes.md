## 关联指标调研：CNN 恐惧与贪婪指数接口

本节记录 2026-10-19 对其他公开接口的检索和实际连通性测试，只作为讨论证据，不代表决定接入 CNN 指数。

### R-001 CNN 网页内部数据端点

- 地址：`https://production.dataviz.cnn.io/index/fearandgreed/graphdata`
- 性质：CNN 页面自身使用的内部 JSON 端点，不是有稳定性承诺的正式公开 API。
- 数据：当前分数、评级、前收盘、一周前、一月前、一年前、约一年历史和各组成指标。
- 实测：使用普通程序请求头时返回 HTTP 418；带合理的浏览器、来源页和 JSON 请求头时返回 HTTP 200。
- 风险：CNN 可随时调整反爬虫策略、地址或数据结构。

### R-002 FearAndGreedGraph 无密钥接口

- 地址：`https://fearandgreedgraph.com/api/fear-greed`
- 文档：`https://fearandgreedgraph.com/data`
- 性质：第三方公开镜像，不是 CNN 官方服务。
- 数据：历史日期、分数、更新时间和各组成指标。
- 实测：HTTP 200、无需密钥、开放 CORS；最新时间为 `2026-10-16T23:59:49+00:00`，最新值 `17.9`，与当时 CNN 返回的 `17.938...` 一致。
- 优点：调用简单，适合低频展示和走势图。
- 风险：增加对小型第三方服务的依赖；可用性和长期维护能力没有官方保证。

### R-003 FearGreedChart 独立综合指数

- 地址：`https://feargreedchart.com/api/?action=all`
- 文档：`https://feargreedchart.com/api-docs`
- 性质：第三方自行计算的美国股票市场情绪指数，不是 CNN 指数镜像。
- 实测：HTTP 200、无需密钥、开放 CORS；返回市场数据、五项组成指标、历史和回测数据。
- 关键差异：同一时点返回分数 `37`，而 CNN 为约 `18`；两者方法和含义不能混用。
- 结论：如果采用，必须使用独立名称和方法说明，不能标注为“CNN 恐惧与贪婪指数”。

### R-004 GitHub/jsDelivr 静态镜像

- 地址：`https://cdn.jsdelivr.net/gh/Darthh/fear-and-greed-index-data@main/data/latest.json`
- 性质：第三方 GitHub 数据集经 CDN 分发。
- 实测：HTTP 200、无需密钥、开放 CORS，但最新数据停留在 `2026-08-14`，不满足当前实时展示需求。
- 结论：当前不适合作为主数据源，最多作为历史备份候选。

### R-005 oanor API

- 文档：`https://www.oanor.dev/api/stockfeargreed-api/openapi.json`
- 文档声称提供指数、组成指标、历史和元数据端点。
- 实测：OpenAPI 文档可以读取，但 `/v1/index`、`/v1/components`、`/v1/history` 和 `/v1/meta` 均返回 HTTP 401。
- 结论：不能视为真正的无密钥公开接口。

### R-006 SentiSense 与 RapidAPI

- SentiSense 提供独立的美国市场情绪模型，但实测端点返回 HTTP 401，需要申请密钥。
- RapidAPI 上存在相关封装服务，但需要平台账户和 API 密钥，免费额度与持续可用性取决于服务商。
- 结论：可以作为有认证的后备选项，不符合“直接无密钥公开接口”的最简方向。

### R-007 使用官方基础数据自行计算

- FRED 提供正式 REST API，可获取部分债券和宏观序列，但需要 API Key。
- Cboe 提供 VIX、期权成交量和 Put/Call Ratio 等公开数据。
- 其他组成项仍需市场行情和广度数据源。
- 结论：来源更透明、可控，但无法简单复刻 CNN 的完整历史口径，开发与维护成本明显更高。

### R-008 更新频率与走势图粒度

#### VIX

- Cboe 官方说明：盘中 VIX 使用 SPX 期权买卖报价快照，每 15 秒计算和发布一次。
- 官方计算时段覆盖 Cboe 全球交易时段和美股常规交易时段，并非只在美股日盘收盘后更新。
- VIX 原始数据适合展示分时走势图，也适合展示日线、月线和年度趋势。
- 免费数据源可能只提供延迟行情或一分钟级采样，应用实际刷新频率应根据采用的数据源确定，不能暗示达到 Cboe 官方 15 秒实时等级。

#### CNN 恐惧与贪婪指数

- CNN 官方说明：各组成指标和综合指数会在新数据可用时重新计算，没有公布固定的秒级或分钟级刷新周期。
- 七项组成数据的更新时间不同，因此 CNN 指数不是统一撮合、固定频率发布的交易所指数。
- CNN 内部端点和已测试第三方镜像主要提供当前快照与日级历史序列，没有稳定、正式的分钟级历史数据。
- 因此 CNN 指数适合展示当前状态和日线趋势，不宜在没有自行采集数据的情况下宣称提供官方分时走势图。

#### 对 CrossETF 的含义

- VIX：可以作为盘中指标，候选刷新间隔为 30～60 秒；走势图可以提供分时和日线周期。
- CNN 指数：候选刷新间隔为 10～30 分钟；走势图以日线为主。
- 如果需要 CNN 分时走势，只能由 CrossETF 自行定时采样并持久化，从开始采集之日起积累，无法从现有公开接口可靠补齐完整历史分时数据。
- 以上间隔仍属于讨论候选，需在最终方案中确认。

### 当前调研结论

- 若目标是显示 CNN 原始分数，CNN 内部端点最接近源头，但需承受非正式接口和反爬虫风险。
- 若目标是无密钥、简单接入，FearAndGreedGraph 当前是最可用的镜像候选，但必须设置缓存、结构校验和失效降级。
- FearGreedChart 是不同方法的独立指数，不能替代或冒充 CNN 指数。
- 当前没有发现兼具 CNN 官方授权、正式 API 文档、无密钥和长期稳定承诺的接口。
