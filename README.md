# A股纳指与标普500 ETF追踪终端 (NasDashboard)

基于第一性原理与公募基金 QDII 联动估值模型构建的轻量级金融看板。实时联动**芝商所纳斯达克期货（CME NQ）**、**标普500期货（CME ES）**与**离岸人民币汇率（USD/CNH）**，估算 A 股场内纳斯达克 100 与标普 500 ETF 的实时日内联动参考估值（实时 EST），动态监控二级市场折溢价率与同指数价差空间。

---

## 🌟 核心功能特性

1. **标的池全自动在线发现与滑动缓存机制**：
   - **在线首选拉取**：每日自动从天天基金全网公募基金代码库动态扫描所有以 `159`（深市）和 `513`（沪市）开头的纳指与标普 ETF，**彻底告别代码写死**，未来新发标的自动感知。
   - **每日持久化缓存 (`nasdaq_symbols_cache.json`)**：在线拉取成功后自动持久化至本地硬盘。
   - **前日缓存无缝兜底**：若遇网络中断或上游接口抖动，**自动无缝降级使用前一日缓存的标的库**，保障盘中行情服务永不中断，并在界面清晰展示缓存日期。
   - **智能自动分类与保守处理**：
     - **纳指 100 综合宽基核心池**（12只）：`513390`（博时）、`513110`（华泰柏瑞）、`159513`（大成）、`159632`（华安）、`159659`（招商）、`159660`（汇添富）、`513870`（富国）、`513300`（华夏）、`159696`（易方达）、`159941`（广发）、`159501`（嘉实）、`513100`（国泰）。
     - **标普 500 综合宽基核心池**（4只）：`159655`（华夏）、`513650`（南方）、`159612`（国泰）、`513500`（博时）。
     - **细分行业 ETF 保守处理**：本系统尚未接入匹配的行业估值数据源，暂停细分行业标的（如 159509、513290）的 EST 模型估算与评级，避免基准错配误导。
2. **联动 EST 估值模型与指标定义**：
   - **官方公布净值 (`nav_t1`)**：标的基金最新披露的官方单位净值（基准发布日期待核验）。
   - **交易所官方 IOPV (`iopv`)**：沪深交易所盘中给出的静态估值及官方溢价率（对照参考）。
   - **实时 EST 参考估值**：以官方公布净值为基准，联动白天连续交易的 **CME 纳指/标普期货（NQ/ES）** 实时涨跌与 **离岸人民币汇率（USD/CNH）** 波动推导出的参考估值。
   - **异常与缺失熔断机制**：外盘期指或汇率基准缺失时直接熔断置空估值，取消任何隐式 IOPV 替代；有效 0.0% 溢价严格保留，无效项无论升降序均稳定沉底。
3. **默认按实时溢价率升序自动排序**：
   - 越靠前估值相对越便宜，自动识别全市场有效最低溢价率标的（全场无效时不展示最低标的）。
4. **同指数标的价差金额示意测算器**：
   - 仅限同跟踪指数标的（如纳指 100 内部）比较，由代码强制限制跨指数计算；
   - 测算指标：**溢价率差（百分点）** 与 **价差金额示意（卖出金额 × 溢价率差）**；
   - 必须注明：**该金额不代表可兑现利润，也不等于换仓后的净值敞口增量**。
5. **KISS 原则极简设计**：
   - **零第三方依赖**：纯 Python 标准库编写服务端（`ThreadingHTTPServer`），无须 `pip install` 任何额外库；
   - **单页面响应式架构**：基于 Vue 3 CDN + Tailwind CSS CDN，支持自适应轮询、手动即时刷新与在线重扫标的。

## 🧮 核心计算公式与模型假设

$$
\text{缩放乘数 ScaleFactor} = (1 + \Delta \text{CME 期货}) \times (1 + \Delta \text{离岸汇率 USD/CNH})
$$

$$
\text{实时 EST} = \text{官方公布 NAV} \times \text{ScaleFactor}
$$

$$
\text{实时溢价率} = \frac{\text{二级市场现价} - \text{实时 EST}}{\text{实时 EST}} \times 100\%
$$

$$
\text{溢价率差 (百分点)} = \text{标的A溢价率} - \text{标的B溢价率}
$$

$$
\text{价差金额示意} = \text{卖出金额} \times \text{溢价率差 (百分点)}
$$

> **⚠️ 模型假设与局限性声明**：
> 1. **基准日期待核验**：当前接口未提供实时官方净值发布日期核验机制，默认作为上一交易日基准；
> 2. **持仓假定**：假定基金 100% 紧密复制对应指数，未计提基金特有的现金留存、外汇衍生品对冲与申赎缓冲；
> 3. **时间对齐与时滞**：尚未解决微观时刻严格对齐与过期行情识别；
> 4. **价差示意局限**：价差金额示意未扣除券商买卖双边佣金、印花经手规费及盘口买卖滑点冲击成本，不代表可兑现利润，也不等于换仓后的净值敞口增量。

## 🚀 极速启动与使用

在终端中进入项目目录，执行以下任一命令即可：

### 方式一：Docker Compose 一键启动（推荐，适合 NAS / 服务器 / 本地）
```bash
docker compose up -d
```
停止服务：
```bash
docker compose down
```

### 方式二：Docker 原生运行
```bash
# 构建轻量镜像（仅约 50MB，无第三方 pip 依赖）
docker build -t etf-dashboard:latest .

# 启动容器并挂载缓存
docker run -d \
  --name etf-dashboard \
  -p 8000:8000 \
  -v $(pwd)/nasdaq_symbols_cache.json:/app/nasdaq_symbols_cache.json \
  --restart unless-stopped \
  etf-dashboard:latest
```

### 方式三：运行本地脚本启动
```bash
./start.sh
```

### 方式四：直接使用 Python 启动
```bash
python3 server.py
```

启动成功后，浏览器打开：
👉 **http://127.0.0.1:8000**

API 接口说明：
* 实时行情数据：`GET http://127.0.0.1:8000/api/quotes`
* 强制在线重扫标的：`GET http://127.0.0.1:8000/api/refresh-symbols`
* 容器健康检查：`GET http://127.0.0.1:8000/health`

## 💡 投资与溢价风控锦囊

- **核心认知：实时溢价率 vs 官方 IOPV 溢价有什么区别？重要吗？**
  - **重要性：至关重要！看错指标可能导致严重的误判亏损。**
  - **官方 IOPV 溢价（盲区大、白天滞后）**：
    交易所行情软件（如通达信、同花顺、各大券商 App）显示的 IOPV，是基于**昨夜已收盘的美股成分股价格**计算的静态估值。白天美股不开盘，官方 IOPV 全天几乎静止不动。**它完全忽略了白天正在交易的芝商所纳指期货（CME NQ）及标普期货（CME ES）的实时涨跌，以及离岸汇率（USD/CNH）波动**。如果白天美股期货大涨 2%，官方 IOPV 根本体现不出来，此时看官方溢价率会被严重虚高误导！
  - **实时溢价率（动态联动模型估算）**：
    本项目立足第一性原理，联动白天纳指/标普期货及离岸人民币汇率跳动，推导折算白天标的资产的实时动态净值（实时 EST 参考估值）。**旨在消除由于白天美股现货休市造成的静态估值盲区，提供更具前瞻性的买贵程度参考**（模型受制于基准日待核验及指数持仓近似假定）。

- **为什么跌了溢价反而高了？**
  溢价率是一个**相对比值**：`(现价 - 实时EST) / 实时EST`。如果昨夜美股大跌 2%，而白天国内场内投资者情绪亢奋、仅微跌 0.5%，分母缩小的速度远快于分子，导致算出来的溢价率不仅没降反而大幅飙升。

- **高溢价买入的隐性炸弹**：
  溢价本质是资金抢筹的泡沫。一旦 QDII 额度宽松或场内情绪退潮，溢价率可能在数天内从 15% 快速回落至 1%~2%。哪怕美股纳指持续上涨，你在场内的持仓也会因杀溢价而遭受 12%~14% 的直接浮亏。

- **场内 vs 场外配置防线**：
  - **场外联接基金**：按真实净值结算，**无一分钱溢价风险**，适合长期无脑自动化定投；
  - **场内 ETF**：适合灵活把握日内波动与同类搬砖套利。买入红线：**溢价 > 5% 绝对禁买**；溢价 > 10% 启动防守，考虑分批高低切换或止盈。
