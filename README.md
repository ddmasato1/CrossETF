# A股纳指与标普500 ETF追踪终端 (NasDashboard)

基于第一性原理与公募基金 QDII 联动估值模型构建的轻量级金融看板。实时联动**芝商所纳斯达克期货（CME NQ）**、**标普500期货（CME ES）**与**离岸人民币汇率（USD/CNH）**，穿透计算 A 股场内纳斯达克 100 与标普 500 ETF 的实时底层公允价值（实时 EST），动态监控二级市场真实折溢价率与套利剪刀差。

---

## 🌟 核心功能特性

1. **标的池全自动在线发现与滑动缓存机制**：
   - **在线首选拉取**：每日自动从天天基金全网公募基金代码库动态扫描所有以 `159`（深市）和 `513`（沪市）开头的纳指与标普 ETF，**彻底告别代码写死**，未来新发标的自动感知。
   - **每日持久化缓存 (`nasdaq_symbols_cache.json`)**：在线拉取成功后自动持久化至本地硬盘。
   - **前日缓存无缝兜底**：若遇网络中断或上游接口抖动，**自动无缝降级使用前一日缓存的标的库**，保障盘中行情服务永不中断，并在界面清晰展示缓存日期。
   - **智能自动分类**：
     - **纳指 100 综合宽基核心池**（12只）：`513390`（博时）、`513110`（华泰柏瑞）、`159513`（大成）、`159632`（华安）、`159659`（招商）、`159660`（汇添富）、`513870`（富国）、`513300`（华夏）、`159696`（易方达）、`159941`（广发）、`159501`（嘉实）、`513100`（国泰）。
     - **标普 500 综合宽基核心池**（4只）：`159655`（华夏）、`513650`（南方）、`159612`（国泰）、`513500`（博时）。
     - **纳指关联行业与细分主题专区**（2只）：`159509`（纳指科技NDXT）、`513290`（纳指生物科技NBI）。
2. **三级 EST 估值穿透模型**：
   - **官方公布 NAV**：标的基金最新披露的官方单位净值（基准锚点，T-1日美股收盘真实净值）。
   - **交易所官方 IOPV**：沪深交易所盘中给出的静态估值及官方溢价率。
   - **实时 EST（核心）**：以 T-1 净值为基准，联动白天连续交易的 **CME 纳指/标普期货（NQ/ES）** 实时涨跌与 **离岸人民币汇率（USD/CNH）** 波动，推导出白天盘中当前美股资产的真实公允价值。
3. **默认按实时溢价率升序自动排序**：
   - 越靠前估值越便宜，全自动锁定**全市场最优估值洼地**（如博时 513390、华泰柏瑞 513110）。
4. **高低切换（溢价剪刀差）测算器**：
   - 支持自由选择已有持仓（如 159501，溢价 ~17%）与拟切换目标（如 513390，溢价 ~11%）。
   - 输入拟换仓股数，实时测算锁定剪刀差收益（%）与增厚资产价值（元），并给出明确的调仓决策评级。
5. **KISS 原则极简设计**：
   - **零第三方依赖**：纯 Python 标准库编写服务端（`ThreadingHTTPServer`），无须 `pip install` 任何额外库，避免环境污染与 PEP 668 报错。
   - **单页面响应式架构**：基于 Vue 3 CDN + Tailwind CSS CDN，支持 3s/5s/10s 自动轮询、手动即时刷新与在线重新同步标的。

## 📡 数据来源与核心作用解析

本系统依托 4 大底层公开高信噪比数据通道，分别承担**全自动标的发现**、**估值物理锚点**、**美股日内跳动驱动**与**外汇跨币种修正**四大关键职责：

| 数据通道 | 数据源与抓取接口 | 核心作用与在模型中的职责 | 刷新频率 / 特性 |
| :--- | :--- | :--- | :--- |
| **全网标的探测器** | **天天基金网公募库**<br>`fund.eastmoney.com` | **动态全自动标的发现**：每日自动扫描沪深两市全量 QDII ETF，智能归类纳指 100、标普 500 与细分主题，彻底杜绝代码写死，新上市标的自动感知并持久化至本地缓存。 | 每日在线扫描一次 / 支持手动触发重扫 |
| **A股交易与官方净值** | **腾讯财经行情接口**<br>`qt.gtimg.cn` | **提供交易现价与估值物理锚点**：<br>1. **现价 (`price`)**：当前二级市场真实成交价（收盘后为终盘价）；<br>2. **官方 T-1 净值 (`nav_t1`)**：基金公司披露的官方真实 NAV（**实时 EST 测算的物理基准锚点**）；<br>3. **官方 IOPV (`iopv`)**：沪深交易所官方盘中静态估值（作为基准对照）；<br>4. **成交额与涨跌幅**：衡量场内流动性深度，避免误入无成交量的流动性陷阱。 | 实时毫秒级（随轮询间隔 5s~30s 刷新） |
| **美股外盘期货驱动** | **芝商所 (CME) 股指期货**<br>通过新浪外盘 `hf_NQ` / `hf_ES` | **白天美股资产波动的实时核心驱动**：<br>美股现货市场白天休市，官方公布的 T-1 净值是静止的，但 CME 纳指期货（NQ）与标普期货（ES）白天连续交易，**白天标的底层资产的真实涨跌完全由 CME 期货跳动决定**。 | 毫秒级实时跳动 |
| **外汇汇率波动修正** | **离岸外汇交易中心**<br>通过新浪外汇 `fx_susdcnh` | **跨币种资产计价偏差修正**：<br>QDII 底层为纯美元计价资产，而国内场内 ETF 以人民币交易。美元兑离岸人民币升贬值直接传导至以人民币计价的公允净值，通过 $\times (1 + \Delta \text{USD/CNH})$ 消除汇率偏差。 | 毫秒级实时跳动 |

## 🧮 核心计算公式

$$
\text{缩放乘数 ScaleFactor} = (1 + \Delta \text{CME NQ 期货}) \times (1 + \Delta \text{离岸汇率 USD/CNH})
$$

$$
\text{实时 EST} = \text{T-1 官方公布 NAV} \times \text{ScaleFactor}
$$

$$
\text{实时溢价率} = \frac{\text{二级市场现价} - \text{实时 EST}}{\text{实时 EST}} \times 100\%
$$

$$
\text{溢价剪刀差} = \text{标的A溢价率} - \text{标的B溢价率}
$$

## 🚀 极速启动与使用

在终端中进入项目目录，执行以下任一命令即可：

### 方式一：Docker Compose 一键启动（推荐，适合 NAS / 服务器 / 本地）
```bash
docker compose up -d
```
停止服务：
```bash
docker compose down
```

### 方式二：Docker 原生运行
```bash
# 构建轻量镜像（仅约 50MB，无第三方 pip 依赖）
docker build -t etf-dashboard:latest .

# 启动容器并挂载缓存
docker run -d \
  --name etf-dashboard \
  -p 8000:8000 \
  -v $(pwd)/nasdaq_symbols_cache.json:/app/nasdaq_symbols_cache.json \
  --restart unless-stopped \
  etf-dashboard:latest
```

### 方式三：运行本地脚本启动
```bash
./start.sh
```

### 方式四：直接使用 Python 启动
```bash
python3 server.py
```

启动成功后，浏览器打开：
👉 **http://127.0.0.1:8000**

API 接口说明：
* 实时行情数据：`GET http://127.0.0.1:8000/api/quotes`
* 强制在线重扫标的：`GET http://127.0.0.1:8000/api/refresh-symbols`
* 容器健康检查：`GET http://127.0.0.1:8000/health`

## 💡 投资与溢价风控锦囊

- **核心认知：实时溢价率 vs 官方 IOPV 溢价有什么区别？重要吗？**
  - **重要性：至关重要！看错指标可能导致严重的误判亏损。**
  - **官方 IOPV 溢价（盲区大、白天滞后）**：
    交易所行情软件（如通达信、同花顺、各大券商 App）显示的 IOPV，是基于**昨夜已收盘的美股成分股价格**计算的静态估值。白天美股不开盘，官方 IOPV 全天几乎静止不动。**它完全忽略了白天正在交易的芝商所纳指期货（CME NQ）及标普期货（CME ES）的实时涨跌，以及离岸汇率（USD/CNH）波动**。如果白天美股期货大涨 2%，官方 IOPV 根本体现不出来，此时看官方溢价率会被严重虚高误导！
  - **实时溢价率（真实公允、精准穿透）**：
    本项目利用第一性原理，通过抓取白天纳指/标普期货及离岸人民币汇率跳动，推导折算白天标的资产的实时动态净值（实时 EST）。**反映的是当下这只 ETF 相对底层美股真实价值的真实买贵程度**，是高低切换、套利和建仓的唯一真实依据。

- **为什么跌了溢价反而高了？**
  溢价率是一个**相对比值**：`(现价 - 实时EST) / 实时EST`。如果昨夜美股大跌 2%，而白天国内场内投资者情绪亢奋、仅微跌 0.5%，分母缩小的速度远快于分子，导致算出来的溢价率不仅没降反而大幅飙升。

- **高溢价买入的隐性炸弹**：
  溢价本质是资金抢筹的泡沫。一旦 QDII 额度宽松或场内情绪退潮，溢价率可能在数天内从 15% 快速回落至 1%~2%。哪怕美股纳指持续上涨，你在场内的持仓也会因杀溢价而遭受 12%~14% 的直接浮亏。

- **场内 vs 场外配置防线**：
  - **场外联接基金**：按真实净值结算，**无一分钱溢价风险**，适合长期无脑自动化定投；
  - **场内 ETF**：适合灵活把握日内波动与同类搬砖套利。买入红线：**溢价 > 5% 绝对禁买**；溢价 > 10% 启动防守，考虑分批高低切换或止盈。
