# CrossETF - A股跨境ETF实时溢价追踪与收盘沉淀终端

极简、坚固的跨境 ETF 实时折溢价量化监控看板。立足境内 A 股交易市场，盘中实时跟踪**纳斯达克 100**、**标普 500** 及科技细分跨境 ETF 的官方 IOPV 溢价率，全自动沉淀每日收盘情绪档案，内置同类标的价差测算。零第三方依赖，专为云主机与服务器 7×24 小时常驻运行打造。

---

## 🌟 核心功能特性

1. **标的池全自动在线发现与滑动缓存机制**：
   - **在线首选拉取**：每日自动从天天基金全网公募基金代码库动态扫描所有以 `159`（深市）和 `513`（沪市）开头的纳指与标普 ETF，**彻底告别代码写死**，未来新发标的自动感知。
   - **每日持久化缓存 (`data/nasdaq_symbols_cache.json`)**：在线拉取成功后自动持久化至本地数据目录。
   - **前日缓存无缝兜底**：若遇网络中断或上游接口抖动，**自动无缝降级使用前一日缓存的标的库**，保障盘中行情服务永不中断，并在界面清晰展示缓存日期。
   - **标的池全覆盖**：
     - **纳指 100 综合宽基核心池**（12只）：`513390`（博时）、`513110`（华泰柏瑞）、`159513`（大成）、`159632`（华安）、`159659`（招商）、`159660`（汇添富）、`513870`（富国）、`513300`（华夏）、`159696`（易方达）、`159941`（广发）、`159501`（嘉实）、`513100`（国泰）。
     - **标普 500 综合宽基核心池**（4只）：`159655`（华夏）、`513650`（南方）、`159612`（国泰）、`513500`（博时）。
     - **细分行业与主题标的**：全面接入交易所官方发布数据，覆盖 `159509`（纳指科技）、`513290`（纳指生物科技）等。
2. **券商官方 IOPV 口径与指标定义**：
   - **实时溢价率**：完全对齐券商交易软件口径，基于交易所官方实时公布的 **IOPV（基金份额参考净值）** 计算：$\frac{\text{场内现价} - \text{IOPV}}{\text{IOPV}} \times 100\%$；
   - **实时估值 (IOPV)**：交易所官方按成份股与最新汇率实时发布的参考净值；
   - **公布净值 (`nav_t1`)**：基金公司披露的上一交易日官方公布单位净值；
   - **宏观联动指标**：持续跟踪芝商所纳指期货（CME NQ）、标普期货（CME ES）与离岸人民币汇率（USD/CNH）作为市场整体宏观水位参考；
   - **空值沉底机制**：未交易或数据缺失标的无论升序降序均稳定沉底，有效 0.0% 溢价正常保留。
3. **默认按实时溢价率升序自动排序**：
   - 越靠前估值相对越便宜，自动识别全市场有效最低溢价率标的（全场无效时不展示最低标的）。
4. **同指数标的价差金额示意测算器**：
   - 仅限同跟踪指数标的（如纳指 100 内部）比较，由代码强制限制跨指数计算；
   - 测算指标：**溢价率差 (%)** 与 **价差金额示意（卖出金额 × 溢价率差）**；
   - 必须注明：**该金额不代表可兑现利润，也不等于换仓后的净值敞口增量**。
5. **手机端与桌面端双视图**：
   - **手机端（`<640px`）**：ETF 以紧凑卡片展示，默认只保留代码/简称、实时溢价率、涨跌幅和现价四项核心数据；点击单条可在原位展开费率、IOPV、净值、成交额、市场、跟踪指数和风险建议；
   - **桌面端（`>=640px`）**：继续使用完整数据表格，保留表头排序与高密度浏览能力；
   - 两种视图共享同一份 Vue 数据和计算逻辑，不复制业务口径。切换指数 Tab 时自动清理展开状态，同时最多展开一个标的。
6. **KISS 原则极简设计**：
   - **零第三方依赖**：纯 Python 标准库编写服务端（`ThreadingHTTPServer`），无须 `pip install` 任何额外库；
   - **单页面响应式架构**：基于 Vue 3 CDN + Tailwind CSS CDN，支持自适应轮询、手动即时刷新与在线重扫标的。
7. **独立市场情绪温度**：
   - 展示 CNN 口径恐惧贪婪指数的当前分数、中文等级、五段色温和最近 30 个自然日趋势；低分代表恐惧，高分代表贪婪；
   - 情绪模块使用独立 `/api/fear-greed`、独立 60 分钟缓存和最后有效数据降级，不参与 ETF 估值、溢价、排序、评级或历史归档；
   - 外部情绪源失败时每 10 分钟允许重试，页面继续显示最后有效数据并标注“缓存数据”；首次无有效数据时明确显示不可用。

| 数据通道 | 数据源与抓取接口 | 核心作用与在模型中的职责 | 刷新频率 / 特性 |
| :--- | :--- | :--- | :--- |
| **全网标的探测器** | **天天基金网公募库**<br>`fund.eastmoney.com` | **动态全自动标的发现**：每日自动扫描沪深两市全量 QDII ETF，智能归类纳指 100、标普 500 与细分主题，彻底杜绝代码写死，新上市标的自动感知并持久化至本地缓存。 | 每日在线扫描一次 / 支持手动触发重扫 |

## 🧮 核心计算公式与模型假设

$$
\text{实时估值} = \text{交易所官方发布 IOPV}
$$

$$
\text{实时溢价率} = \frac{\text{二级市场现价} - \text{官方 IOPV}}{\text{官方 IOPV}} \times 100\%
$$

$$
\text{宏观环境联动乘数} = (1 + \Delta \text{CME 期货}) \times (1 + \Delta \text{离岸汇率 USD/CNH})
$$

$$
\text{溢价率差 (\%)} = \text{标的A溢价率} - \text{标的B溢价率}
$$

$$
\text{价差金额示意} = \text{卖出金额} \times \text{溢价率差 (\%)}
$$

> **⚠️ 模型假设与局限性声明**：
> 1. **基准日期待核验**：当前接口未提供实时官方净值发布日期核验机制，默认作为上一交易日基准；
> 2. **持仓假定**：假定基金 100% 紧密复制对应指数，未计提基金特有的现金留存、外汇衍生品对冲与申赎缓冲；
> 3. **时间对齐与时滞**：尚未解决微观时刻严格对齐与过期行情识别；
> 4. **价差示意局限**：价差金额示意未扣除券商买卖双边佣金、印花经手规费及盘口买卖滑点冲击成本，不代表可兑现利润，也不等于换仓后的净值敞口增量。

## 🚀 极速启动与使用

在终端中进入项目目录，执行以下任一命令即可：

### 方式一：Docker Compose 一键启动（推荐，适合 NAS / 服务器 / 本地）
```bash
docker compose up -d
```
停止服务：
```bash
docker compose down
```

### 方式二：Docker 原生运行
```bash
# 构建轻量镜像（仅约 50MB，无第三方 pip 依赖）
docker build -t cross-etf:latest .

# 启动容器并挂载独立数据目录（支持安全原子替换）
docker run -d \
  --name cross-etf \
  -p 8000:8000 \
  -v $(pwd)/data:/app/data \
  --restart unless-stopped \
  cross-etf:latest
```

### 方式三：运行本地脚本启动
```bash
./start.sh
```

### 方式四：直接使用 Python 启动
```bash
python3 server.py
```

启动成功后，浏览器打开：
👉 **http://127.0.0.1:8000**

API 接口说明：
* 实时行情数据：`GET http://127.0.0.1:8000/api/quotes`
* 恐惧贪婪指数：`GET http://127.0.0.1:8000/api/fear-greed`
* 每日收盘历史归档：`GET http://127.0.0.1:8000/api/history`（支持 `?days=30` 参数）
* 强制在线重扫标的：`GET http://127.0.0.1:8000/api/refresh-symbols`
* 容器健康检查：`GET http://127.0.0.1:8000/health`

## 💡 投资与溢价风控锦囊

- **核心认知：实时溢价率 vs 官方 IOPV 溢价有什么区别？重要吗？**
  - **重要性：至关重要！看错指标可能导致严重的误判亏损。**
  - **官方 IOPV 溢价（盲区大、白天滞后）**：
    交易所行情软件（如通达信、同花顺、各大券商 App）显示的 IOPV，是基于**昨夜已收盘的美股成分股价格**计算的静态估值。白天美股不开盘，官方 IOPV 全天几乎静止不动。**它完全忽略了白天正在交易的芝商所纳指期货（CME NQ）及标普期货（CME ES）的实时涨跌，以及离岸汇率（USD/CNH）波动**。如果白天美股期货大涨 2%，官方 IOPV 根本体现不出来，此时看官方溢价率会被严重虚高误导！
  - **实时溢价率（动态联动模型估算）**：
    本项目立足第一性原理，联动白天纳指/标普期货及离岸人民币汇率跳动，推导折算白天标的资产的实时动态净值（实时 EST 参考估值）。**旨在消除由于白天美股现货休市造成的静态估值盲区，提供更具前瞻性的买贵程度参考**（模型受制于基准日待核验及指数持仓近似假定）。

- **为什么跌了溢价反而高了？**
  溢价率是一个**相对比值**：`(现价 - 实时EST) / 实时EST`。如果昨夜美股大跌 2%，而白天国内场内投资者情绪亢奋、仅微跌 0.5%，分母缩小的速度远快于分子，导致算出来的溢价率不仅没降反而大幅飙升。

- **高溢价买入的隐性炸弹**：
  溢价本质是资金抢筹的泡沫。一旦 QDII 额度宽松或场内情绪退潮，溢价率可能在数天内从 15% 快速回落至 1%~2%。哪怕美股纳指持续上涨，你在场内的持仓也会因杀溢价而遭受 12%~14% 的直接浮亏。

- **场内 vs 场外配置防线**：
  - **场外联接基金**：按真实净值结算，**无一分钱溢价风险**，适合长期无脑自动化定投；
  - **场内 ETF**：适合灵活把握日内波动与同类搬砖套利。买入红线：**溢价 > 5% 绝对禁买**；溢价 > 10% 启动防守，考虑分批高低切换或止盈。
